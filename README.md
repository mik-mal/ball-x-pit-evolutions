# ball-x-pit-evolutions

An interactive visualization tool for exploring ball evolution paths in the game Ball X Pit.

## Features

- **Interactive Evolution Trees**: View complete evolution paths for Nosferatu, Satan, Black Hole, and Nuclear Bomb
- **Hover Tooltips**: See detailed descriptions and abilities for each ball
- **Path Highlighting**: Click on final evolutions to highlight their complete evolution path
- **Lineage Filtering**: Toggle individual evolution trees on/off using filter buttons
- **Multi-lineage Indicators**: Balls used in multiple evolution paths display radial gradients showing all their lineages

## Live Demo

Visit the live interactive visualization: https://mik-mal.github.io/ball-x-pit-evolutions/

## How to Use

1. **Hover** over any ball to see its name and ability description
2. **Click** on final evolution balls (Nosferatu, Satan, Black Hole, Nuclear Bomb) to highlight their complete evolution path
3. **Toggle** lineage buttons at the top to show/hide specific evolution trees
4. **Explore** the connections to understand which base balls combine to create evolved balls

## Evolution Paths

### Nosferatu (Red)
Base balls → Vampire Lord, Mosquito King, Spider Queen → Nosferatu

### Satan (Orange)
Base balls → Incubus, Succubus → Satan

### Black Hole (Purple)
Base balls → Sun → Black Hole

### Nuclear Bomb (Green)
Base balls → Bomb → Nuclear Bomb
